🎵 Spotify Streaming Analytics Dashboard – Power BI

🚀 Project Overview

This project presents an interactive Power BI dashboard built to analyze Spotify streaming data and evaluate music performance across songs, artists, and albums.
The dashboard transforms raw streaming data into clear visual insights, helping identify popularity trends, listener behavior, and top-performing content through dynamic KPIs and drill-down analysis.

🎯 Objectives

Monitor overall streaming performance

Measure artist and song popularity

Analyze album type distribution

Compare explicit vs non-explicit content

Track monthly listening trends

Enable detailed exploration at artist and song level

📊 Features

Dynamic KPI cards (Distinct Songs, Artists, Avg Duration, Popularity)

Artist and song ranking analysis

Album type distribution (Album / Single / Compilation)

Explicit vs non-explicit content comparison

Monthly popularity trends

Multi-page navigation (Home, Overview, Artists, Songs)

Interactive filters and drill-down visuals

Spotify-inspired modern UI design

🧠 Key Insights

Streaming popularity is concentrated among a small number of top artists

Album releases account for the majority of available tracks

Monthly trends show fluctuations in listener engagement across the year

Explicit songs represent a significant share of total streams

Hit tracks consistently outperform average songs in popularity metrics

Successful artists tend to produce multiple high-performing songs rather than single hits

Average song duration remains consistent around the 3–4 minute range

🛠️ Technologies Used

Power BI

DAX (Data Analysis Expressions)

Data Modeling (Star Schema)

Data Cleaning & Transformation

CSV / Excel datasets
